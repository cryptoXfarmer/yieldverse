## 💡 CUSTOMIZATION:

### Changer les couleurs:
Edit `tailwind.config.ts`:
```typescript
colors: {
  space: {
    purple: '#YOUR_COLOR',
    // etc...
  }
}
```

### Ajouter un jeu:
Copy/paste un game card dans `app/page.tsx`

### Modifier les animations:
Edit `app/globals.css`
